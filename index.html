Robotics Software Engineering In Practice

I'm Robin, a software engineer focused on robotics, safety-relevant validation, and real-world robot systems.

Since joining FERCHAU at SICK AG, I have been working on safety-relevant validation scenarios for mobile robots, connecting software, robot control, and precise pose tracking in real test environments.

EXPERIENCE

Current Work & Previous Roles

A compact overview of my path from robotics research and application development to industry work on safety-relevant mobile robot systems.

Software Engineer Robotics (Ferchau GmbH)Sep. 2025 - Present

I set up and execute manual, safety-relevant validation scenarios for mobile robot systems in real test environments. The work combines ROS 2, C++, Python, UR and AGV robot control, LidarLoc-based pose tracking, and RTDE communication, with a strong focus on reliable test execution and traceable validation quality.

Software Development & ResearchOct. 2023 - Oct. 2024

During my research internship in Lisbon, I developed and tested ROS-based modules for autonomous navigation. My work focused on SLAM, local planning, and improving pose estimation for mobile robots, connecting algorithmic ideas with experiments on real robotic systems.

Software EngineerMar. 2023 - Nov. 2023

I developed and maintained Odoo ERP workflows, implemented process automation, and supported contract management as part of second-level support. The role strengthened my practical experience with Python, SQL, business processes, and production software maintenance.

Software Engineer & UI DesignSep. 2020 - Sep. 2021

I built a .NET/WPF document archiving application from initial requirements analysis through acceptance and company-wide rollout. The project involved stakeholder communication, UI design, SQL integration, and practical delivery of a tool that remains in daily use.
